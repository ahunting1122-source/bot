# Orbit 项目笔记

## 项目目标

做一个本地优先的个人助手，连接本地文件与 Web 平台，理解用户目标并逐步执行。

## 技术选择

- Python 3.12 + FastAPI 提供接口。
- LangGraph 负责编排工具调用和用户接管。
- SQLite 保存会话、任务与长期偏好。
- Playwright 操作专用浏览器，复用用户登录状态。
- React 展示对话、执行过程与任务产物。

## 当前任务

2. 配置 GitHub 仓库并读取相关 Issue。
3. 在专用浏览器中登录 Notion，测试摘要追加。

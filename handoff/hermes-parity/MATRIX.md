## 命令面指标（**不参与**完成度计数）

上面 180 条是**能力行**（Hermes 有这个，Orbit 有没有）。命令面完成度是**另一种**问题，
混在同一个分母里会同时污染两个数字，所以单列。

这一节不手抄数字——**手抄的比率必然过期**（原先 1.17 写的 506/290/28/188 早已和实际
对不上）。以下由 `scripts/matrix_stats.py` 每次现算：

```
python scripts/matrix_stats.py            # 完成度 + 条目数
python -c "from app.cli import REGISTRY; ..."   # 命令面 state 分布
```

含义：
- **能力完成度**（上面的 180 条）= 目标达成度，这是本项目的完成标志。
- **命令面完成度** = `REGISTRY` 里 `done / (done + partial + todo)`，衡量"每条命令
  是否都有真实现"。它低于能力完成度是正常的：一条命令可以因为"远程源无网络"而
  `partial`，但对应的**能力**（比如"能装技能"）在本机是完备的。
- `todo` 命令调用时 exit 3 并给出完整命令路径与排期波次（不会静默失败）。
